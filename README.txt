# 🛸 Tradutor Intergaláctico

Sistema de linha de comando que traduz "sinais alienígenas" para português, 
com suporte a tradução de palavras únicas ou frases completas.

## ✨ Funcionalidades
- Tradução de palavra única
- Tradução de frase completa (múltiplas palavras)
- Tratamento de sinais desconhecidos (retorna `[DESCONHECIDO]` em vez de quebrar)

## 🛠️ Tecnologias
- Python 3.x
- Tratamento de exceções (`try/except`)
- Manipulação de strings (`split`, `join`, `upper`, `lower`)

## ▶️ Como rodar
\`\`\`bash
git clone https://github.com/gabrilopesm/tradutor-intergalatico.git
cd tradutor-intergalatico
python tradutor.py
\`\`\`
